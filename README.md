# [Nombre del Proyecto]

## 📌 Overview
Dominican population according to he last Senso {2022) which is the method used to count the amount of people in the country,
this app translate all the data into a complete dashboard dividing gender, provinces, with modern grafics and more

## 🚀 Tech Stack
- **python:** streamlit, pandas, matplotlib


## ⚙️ How to Run Locally
1. Clone the repo: `git clone [url]`
2. Setup: `pip install -r requirements.txt
e`, `streamlit run app.py
`
